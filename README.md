# Night of the Dead

Text-based game "Night of the Dead" (Russian: "Ночь мертвецов") by NecRabbit.

The game is in Russian and developed for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/?id=night_of_dead).

The game was first published on March 13, 2026.

Interactive fiction identifier (IFID) of the game: EB943722-00C6-4F64-B02B-7D370706A1EE

## Description

…Закончилось все тем, что ты жёстко проигрался! Спустил на автоматах и рулетке все до последнего цента! Продал машину. Заложил дом. И вот, когда на пороге уже замаячили приставы с предписанием о выселении, только тогда ты пришёл в себя. Но было поздно. Вариантов у тебя, прямо скажем, оставалось не много: идти ночевать под Бруклинский мост или ограбить банк…
Впрочем, был ещё третий вариант. Выход. Спасение. Рубиновое колье твоей тётушки, погребённое вместе с ней в фамильном склепе на старом кладбище где-то в захолустье Луизианы. Дурацкая последняя воля усопшей, которую не решились нарушить её многочисленные родственнички. Но теперь она может тебя спасти! Ты никогда не мечтал стать грабителем могил, но выбора нет… Немедля ни минуты, ты отправился на то самое кладбище.
